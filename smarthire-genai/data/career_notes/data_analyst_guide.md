# Data Analyst Career Guide & Roadmap

## Overview
A Data Analyst inspects, cleans, transforms, and models data to uncover actionable business insights, identify operational bottlenecks, and support data-driven decision-making.

## Essential Skills & Tools
1. **Advanced SQL & Relational Databases**:
   - Complex SELECT queries, multi-table JOINs (INNER, LEFT, FULL).
   - Aggregate functions, GROUP BY, HAVING.
   - Window Functions: ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD().
   - Common Table Expressions (CTEs) and subqueries.
   - Performance indexing and query plan analysis.

2. **Data Manipulation & Scripting**:
   - Python: Pandas (dataframes, merging, grouping, reshaping), NumPy.
   - Data cleaning: Handling missing values, deduplication, date/time parsing.
   - Statistical libraries: SciPy, Statsmodels.

3. **Data Visualization & Business Intelligence (BI)**:
   - Tableau: Calculated fields, LOD expressions, interactive dashboard actions.
   - Power BI: DAX formulas, Power Query data transformation, star-schema data modeling.
   - Python Visualization: Matplotlib, Seaborn, Plotly for storytelling.

4. **Statistics & Business Acumen**:
   - Descriptive statistics: Mean, median, standard deviation, percentiles.
   - Inferential statistics: Hypothesis testing, p-values, confidence intervals.
   - A/B Testing: Sample size determination, variant evaluation.
   - Key business metrics: Churn rate, Customer Acquisition Cost (CAC), Lifetime Value (LTV), Conversion Rates.

## Practical Learning Roadmap
- **Step 1: SQL Mastery (Weeks 1-4)**: Solve 50+ real-world SQL questions on LeetCode/StrataScratch covering CTEs and Window Functions.
- **Step 2: Python for Data Analysis (Weeks 5-8)**: Practice EDA on messy Kaggle datasets using Pandas and Seaborn.
- **Step 3: BI Tool Specialization (Weeks 9-12)**: Build and publish 2 Tableau Public or Power BI dashboards addressing a specific business scenario (e.g., retail sales or churn).
- **Step 4: Portfolio Development (Weeks 13-16)**: Write detailed case studies explaining business context, findings, and strategic recommendations.
