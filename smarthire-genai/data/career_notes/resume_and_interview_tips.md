# High-Impact Resume & Technical Interview Guide

## Anatomy of an ATS-Friendly Tech Resume
1. **Clear, Single-Column Layout**:
   - Modern Applicant Tracking Systems (ATS) parse single-column layouts much more reliably than multi-column graphic designs.
   - Avoid tables, complex graphics, or text boxes inside header/footer bands.
   - Use standard section headings: Professional Summary, Education, Technical Skills, Work Experience / Internships, Projects, Certifications.

2. **The Google XYZ Resume Bullet Formula**:
   - Instead of listing duties ("Responsible for writing backend APIs"), use the XYZ formula:
     *Accomplished [X] as measured by [Y], by doing [Z].*
   - Example Before: "Helped build microservices in Python."
   - Example After: "Engineered 12+ RESTful microservice endpoints in FastAPI and PostgreSQL, reducing API response latency by 35% for 15,000 daily active users."

3. **Skills Categorization**:
   - Group skills logically: Languages, Frameworks & Libraries, Databases, Cloud & DevOps Tools.
   - Avoid subjective skill rating bars (e.g., "Python: 85%"), which provide no informative value to recruiters.

4. **Projects Section**:
   - College graduates and junior engineers should highlight 2-3 substantial projects.
   - Detail the problem solved, tech stack, architecture, and include working live deployment and GitHub repository links.

## Technical Interview Preparation
1. **Coding & DSA (Data Structures & Algorithms)**:
   - Practice active problem solving on LeetCode/NeetCode 150.
   - Talk through your thought process: Clarify constraints, propose a brute force solution, analyze Big-O complexity, and then optimize.
2. **Behavioral Questions (STAR Method)**:
   - Structure answers using: Situation, Task, Action, Result.
   - Prepare stories demonstrating conflict resolution, handling project ambiguity, learning new technologies quickly, and delivering under deadlines.
