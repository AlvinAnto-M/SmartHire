# Cloud Infrastructure & DevOps Career Guide

## Overview
Cloud Engineers and DevOps professionals design resilient cloud infrastructure, automate code delivery pipelines, and ensure high availability, scalability, and security of distributed software services.

## Fundamental Pillars
1. **Operating Systems & Scripting**:
   - Linux administration: Bash shell scripting, permissions, systemd services, SSH, networking commands (curl, netstat, iptables).
   - Python scripting for cloud automation and API interaction.

2. **Cloud Service Providers**:
   - Amazon Web Services (AWS) or Google Cloud Platform (GCP) or Microsoft Azure.
   - Core services: Compute (EC2, Lambda, Cloud Run), Storage (S3, Cloud Storage), Networking (VPC, Subnets, Route tables, Load Balancers), IAM (roles, policies, least privilege principle).

3. **Containers & Orchestration**:
   - Docker: Writing efficient multi-stage Dockerfiles, image caching, container networking.
   - Kubernetes (K8s): Pods, Deployments, Services, Ingress, ConfigMaps, Secrets, Helm charts.

4. **Infrastructure as Code (IaC)**:
   - Terraform: HCL syntax, provider configuration, state file management, modular architecture.

5. **CI/CD Pipelines & Monitoring**:
   - Continuous Integration / Delivery: GitHub Actions, GitLab CI, Jenkins.
   - Observability: Prometheus (metrics collection), Grafana (dashboards), ELK Stack / Loki (log aggregation).

## Career Milestones
- **Level 1**: Gain Linux fluency and earn an entry certification (AWS Certified Solutions Architect Associate).
- **Level 2**: Containerize multi-tier web applications with Docker Compose and deploy to AWS ECS or GCP Cloud Run.
- **Level 3**: Provision reproducible infrastructure using Terraform and automate testing and deployment with GitHub Actions.
